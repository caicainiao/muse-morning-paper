5. **Launch HN: Rivet (YC W23) – Scale and Orchestrate Agents on S3**
   摘要：Rivet 推出面向 Agent 工作负载的编排器 Rivet Actors：每个 Agent 一个长驻进程、带内存状态与 SQLite（存 S3），自称冷启动 p99 4.99 毫秒、每个 Actor 仅 72KB 内存，把 Agent 循环放在沙箱之外以缩小信任边界。

6. **和你相关的 1 条：Claude Code sends your email address to websites**
   摘要：用户报告 Claude Code 在联网搜索时把个人邮箱放进了 curl 的 User-Agent 请求头（如为满足维基百科的脚本客户端标识要求），招来大量诈骗邮件；Anthropic 员工回应：这不是设计的功能，而是模型不可预测行为，v2.1.317 起内置的 cc-plugin-privacy 模块会确定性拦截此类行为，且默认开启；原始问题最早 7 月就有人提。
   为什么值得看：你日常用 Claude Code 做攻坚——先确认已升级到 2.1.317 或更高版本，否则联网搜索时你的邮箱可能正被发给任意第三方网站。
   点数：254 点 / 71 评论（08:03 快照）
   链接：https://github.com/anthropics/claude-code/issues/107757
